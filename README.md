## 🚀 Publicar en GitHub Pages (`https://nachofari.github.io/`)

1. Crea un repositorio público en GitHub llamado **`NachoFari.github.io`**.
2. Sube el contenido de esta carpeta:
   ```bash
   git init
   git add .
   git commit -m "feat: portafolio inicial NachoFari"
   git branch -M main
   git remote add origin https://github.com/NachoFari/NachoFari.github.io.git
   git push -u origin main
   ```
3. En GitHub ve a **Settings → Pages → Deploy from a branch (`main` / `/ (root)`)** y guarda.
4. En ~1 minuto estará publicado en **`https://nachofari.github.io/`**.
